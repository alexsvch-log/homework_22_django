## Требования
* **Python** версии 3.14 или выше
* **Django** версии 4.2+ / 5.0+
* СУБД **SQLite** (встроена в Python, дополнительных установок не требуется)

## Настройка окружения и зависимостей

1. **Клонируйте репозиторий и перейдите в корень проекта:**
   ```bash
   git clone <ссылка_на_ваш_репозиторий>
   cd homework_22_django
   ```

2. **Создайте и активируйте виртуальное окружение:**
   * **Windows:**
     ```bash
     python -m venv .venv
     .venv\Scripts\activate
     ```
   * **macOS / Linux:**
     ```bash
     python3 -m venv .venv
     source .venv/bin/activate
     ```

3. **Установите зависимости:**
   ```bash
   pip install django
   # Если в проекте используется файл зависимостей:
   # pip install -r requirements.txt
   ```

4. **Инициализируйте базу данных (Примените миграции):**
   *Поскольку файл локальной базы данных `db.sqlite3` добавлен в исключения `.gitignore`, его структуру необходимо воссоздать локально на основе файлов миграций приложения:*
   ```bash
   python manage.py migrate
   ```

## Инструменты разработки (Linting)
Для проверки качества кода и соответствия стандарту PEP 8 в проекте используются следующие линтеры (при необходимости установите их в ваше окружение):

* **Flake8** — для статического анализа кода:
  ```bash
  flake8 catalog/
  ```
* **Black** — для автоматического форматирования кода:
  ```bash
  black catalog/
  ```

* **isort** — для автоматического форматирования кода:
  ```bash
  black catalog/
  ```
  
## Использование

1. **Запустите локальный сервер разработки Django:**
   ```bash
   python manage.py runserver
   ```
2. **Откройте приложение в браузере:**
   Перейдите по адресу [http://127.0.0](http://127.0.0)

### Основные разделы сайта:
* **`/catalog/home/`** — Главная страница с каталогом нужных и полезных вещей.
* **`/catalog/contacts/`** — Форма обратной связи для отправки сообщений (обрабатывает POST-запросы и безопасно сохраняет данные пользователя во временную сессию).
